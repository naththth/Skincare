# Pele Nath PWA

Arquivos para publicar o app Pele Nath no GitHub Pages.

## Estrutura

- `index.html`
- `manifest.json`
- `service-worker.js`
- `icons/icon-192.png`
- `icons/icon-512.png`

Depois de publicar no GitHub Pages, abra o link no Chrome ou Samsung Internet e use **Adicionar à tela inicial** ou **Instalar app**.
