# Pele Nath PWA com Supabase

Essa versão salva os dados em:
- Supabase, como banco na nuvem
- IndexedDB, como backup local/offline no navegador

Arquivos principais:
- `index.html`
- `manifest.json`
- `service-worker.js`
- `icons/icon-192.png`
- `icons/icon-512.png`

Depois de subir no GitHub Pages, aguarde alguns minutos e abra o link no celular.
